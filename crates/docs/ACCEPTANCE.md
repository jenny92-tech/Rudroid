# 当前支持与验收范围

Rudroid 的验收覆盖指定游戏、构建和固件上的短程路径。原生加载、图形预检、
实屏、输入、数字音频、保存与退出分别检查；通过其中一项不能替代其余项目。
本文保留当前支持边界，构建与部署步骤见 [BUILD-DOCKER](../../BUILD-DOCKER.md)。

| 丝之歌 | 6000.0.58f1 | 语言恢复、读档、移动与动作、保存、菜单及快捷键退出；有界 GLES/Vulkan 对照 |

这些路径在不同验收基线上完成，并非每次更新套件都重跑全部玩法。
后续原生预检、安装完整性或日志检查不能记作新一轮画面、玩法及性能验收。
活跃游戏进程的 PCM 证明数字音频输出，不代替实体扬声器听感。

## 默认配置与图形准入

五标题新状态默认 **OpenGL ES、75% 渲染**，保留已有合法用户选择。
丝之歌和吸血鬼 1.14 可在高级页手动选择 Vulkan，开放条件同时包括：

- 游戏及固件名称、完整 device-tree 条目匹配已登记组合；
- 运行库编译能力、标题声明和局部运行依赖齐全；
- 有界原生 Vulkan 预检通过。

当前登记 TrimUI / `allwinner,a523` 和 Loong / `rockchip,rk3566-rk817-tablet`。
未知设备在 GPU 探测前禁用 Vulkan；IP 或相似 SoC 名称不用于兼容性判断。
原生预检不加载游戏、不报告游戏帧，不能证明完整 shader 或玩法可用。

TrimUI 使用局部 Wayland 客户端及私有 Weston 会话，沿用系统 GPU 驱动。
**仅 A523 丝之歌**强制私有 Weston 全尺寸合成，75% 游戏渲染为 960×540、
送屏为 1280×720，以规避缩小缓冲直接扫描时的实屏条纹。该路径已有实屏及移动检查，
不能据此把旧完整高特效读档黑屏判为通过。其他标题与 MiniLoong 不套用此策略。
详细条件见 [运行策略](RUNTIME-POLICY.md#可选-vulkan-后端)与
[显示边界](PERFORMANCE-AUDIT.md#显示与-vulkan-边界)。

常用设置与高级设置、禁用项和后端选择由共享启动器维护。配置按游戏原子合并，
保留未拥有的键；内存档、画质、帧率、渲染线程模式分别控制，不隐式互相替代。

## 生命周期与标题行为

丝之歌使用字符串 `M2H_lastLanguage` 保存语言；旧整数 `GameLang` 不构成恢复契约。
语言插件受完整元数据与 enum ABI 门控，在正常切换后保存实际枚举名并请求
PlayerPrefs.Save。跨进程语言恢复已检查；异常断电持久化仍不在保证范围内。

丝之歌菜单快速退出仅在引擎正常请求停止且偏好同步写入成功后走进程终止边界，
保留原生状态至进程结束，避免在已停止状态上重复析构。失败、异常、快捷键及测试
帧数上限仍执行完整清理；其他标题默认不启用。它改善退出等待，不代表运行期
帧率或内存收益。保存及退出必须继续通过新进程重读检查。

A523 丝之歌可选渲染线程分配仅在已核验拓扑上开启；FMOD 混音分配只用于该标题的
Vulkan 路径。这些设备策略与 Unity single/multi 模式独立，见
[线程策略](PERFORMANCE-AUDIT.md#线程策略)。

## Release 与交付要求

正式交付必须是完整的同 kit Release：loader 和全部能力库具有正向 Release 标记，
没有 Debug、测试或训练成员，并通过成员清单、指纹及 Linux ABI 审计。
核心 kit 当前直接依赖上限为 GLIBC 2.28；可选 Wayland 客户端另行审计，不能放宽核心门禁。

已记录的双机正式日志策略库存为 `rust-kit-6d16cf1140c86bcf`；该身份仅描述对应产物，
不能用于后续源码重建。后续源码或构建输入变化必须生成新身份，再进行生产审计。
原有玩法基线不因日志策略部署而自动扩展为新套件完整玩法回归。

正常运行只保留有界异常上下文，正常退出不产生常规游戏日志；完整诊断须显式设置
`RUDROID_DIAGNOSTICS=1`。验收后重新构建安静的生产套件，不交付测试过程中生成的库。
产物需附源码修订或源码清单、kit/features、成员、配置、许可与校验信息。
公开源码包不包含游戏、存档、私有测量或设备安装回执。

固定公共基础镜像配方已有本机重建检查；其他主机的首次构建与每次产物交付仍需验证。
当前源码说明不等同于已重新构建、部署或执行本轮真机验收。

## 已知失败与未验证范围

- A523 丝之歌完整高特效 Vulkan 读档黑屏未通过；早期局部黑块与捕获伪影尚未完全区分。
  实屏条纹的有界修复不覆盖这些问题。
- Weston 外部捕获曾触发断言，不能把显示服务丢失后的正常退出当作玩法通过。
  更早的 RGA 错误及内核 Oops/panic 根因未定，不能与用户态捕获断言合并归因。
- 1 GiB 上的短程通过不保证低内存下完整可玩、全关卡稳定 30 帧或长期无泄漏。
  成功呈现计数不能替代真实画面，性能口径见 [性能决策](PERFORMANCE-AUDIT.md)。
- ARM32、Unity Mono、R36S、其他固件与游戏、所有控制器及物理热插拔、完整 shader
  覆盖和全流程玩法仍需单独验收。

新设备与标题按 [移植指南](HANDHELD-PORTING-WORKFLOW.md)逐阶段检查，
新产物按 [生产部署顺序](../../BUILD-DOCKER.md#生产部署顺序)交付。
